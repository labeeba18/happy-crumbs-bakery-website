# 🍪 Happy Crumbs Bakery Website

A beautifully designed and fully responsive bakery website built using **HTML, CSS, and JavaScript**.  
This project showcases a modern UI with smooth user experience, interactive cart functionality, and aesthetic design.

---

## ✨ Features

- 🍪 Elegant bakery-themed UI design
- 📱 Fully responsive (mobile + desktop)
- 🛒 Add to Cart functionality
- ➕ Dynamic cart item counter
- ❌ Remove items from cart
- 💰 Total price calculation
- 🖼️ Image gallery section
- 📩 Contact form UI
- 🎯 Smooth scrolling navigation

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling & layout
- **JavaScript (Vanilla JS)** – Functionality
